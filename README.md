# devhub-tools/homebrew-tap

```bash
brew install devhub-tools/tap/querydesk
```

| Cask        | What it is                                                                     |
| ----------- | ------------------------------------------------------------------------------ |
| `querydesk` | [QueryDesk CLI](https://github.com/devhub-tools/querydesk-cli): connect Postgres and MySQL clients to QueryDesk over HTTPS |

After a CLI release, run the [QueryDesk CLI workflow](.github/workflows/querydesk.yml) from the Actions tab (or `gh workflow run querydesk.yml --repo devhub-tools/homebrew-tap`). It points the cask at the latest release.
